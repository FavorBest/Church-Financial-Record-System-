# Church Money Record System

A Supabase-powered church financial record system.

## Features
- Secure Supabase email/password login
- Dashboard
- Income records
- Expense records
- Church funds
- Basic financial reports
- Role-based navigation
- USD/LRD fund support
- Row Level Security through Supabase

## Deployment
This is a static website and can be hosted on GitHub Pages, Netlify, or another static host.

The frontend uses the Supabase publishable key. Never place a Supabase service-role/secret key in browser code.

## Supabase project
The app is configured for the existing Church Choir Attendance Supabase project, which now contains the financial tables. The financial website remains separate from the choir website.
